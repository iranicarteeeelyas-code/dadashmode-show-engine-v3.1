# ROUND SYSTEM — 6 COMPETITION STAGES

### Round 1: برج لیوان (Cup Tower Stack)
- **Objective:** Stack 10 cups in a 1-2-3-4 pyramid using only ONE hand.
- **Validation:** Tower must stand undisturbed for 2 full seconds.
- **Reward:** +10 Banked Seconds.

### Round 2: فاصله را انتخاب کن (Choose the Distance)
- **Choices:** Green (+5s) | Yellow (+10s) | Red (+20s).
- **Rule:** 3 attempts. Choice is locked prior to the first throw.

### Round 3: لقمهٔ مرموز (Mystery Box Bite)
- **Boxes:** 1 through 6.
- **Local Random Distribution:** Two boxes +15s | One box steals 5s | Three boxes empty.
- **Rule:** Distribution is strictly handled by local pseudo-random seed, inaccessible to LLMs.

### Round 4: دستکش و پازل (Oven Mitts & Wolf Emblem)
- **Objective:** Wear oven mitts, open taped crate, assemble 4 Wolf puzzle pieces, hit finish line.
- **Reward:** +15s and a Sabotage Card (Giant Gloves, 5s Start Delay, or Only 2 Attempts).

### Round 5: حالت ریسک زمان (Time Risk Powers)
- **Powers:** Hint (15s), Extra Life (25s), Opponent Slowdown (20s), Hard Mode (30s), Double or Nothing, Comeback All-In (+50s / -30s).
- **Lock Rule:** Powers are locked before round start.

### Round 6: توالی نهایی (The Final Sequence & Vault)
- **Stage 1:** Blindfolded Drawing from memory -> Code 1.
- **Stage 2:** Memory Structural Reconstruction -> Code 2.
- **Stage 3:** Logic Deduction challenge combining clues -> Code 3.
- **Stage 4:** Golden Vault Unlock.
