# قالب سناریو و فایل قسمت

## دو راه برای دادن سناریو
1. **هوش مصنوعی (پیشنهادی):** هر متنی (فیلم‌نامه، دفتر کارگردانی، لیست دیالوگ، حتی یادداشت‌های نامرتب) را در «سناریو و کارگردانی» بچسبانید یا فایلش را بارگذاری کنید و «درک کامل با هوش مصنوعی» را بزنید. خروجی: خلاصه، لحن، شخصیت‌ها، ضرب‌آهنگ، یادداشت کارگردان، مراحل (معرفی تمام‌صفحه، قوانین انیمیشنی، شمارش، بازی زنده، بانک، برنده) و دیالوگ‌ها با لحن مناسب هر لحظه.
2. **قالب استاندارد (بدون اینترنت):** نمونه در `episodes/template-script.md`.

## قواعد قالب استاندارد
| خط | معنی |
|---|---|
| `نام قسمت: ...` `واحد: ثانیه` `بانک اولیه: 20` `بازیکن: نام، #رنگ` | اطلاعات قسمت (قبل از اولین مرحله) |
| `## [نوع] {بازی} عنوان` | شروع مرحله. نوع: افتتاحیه، معرفی، قوانین، شمارش، بازی، بانک، دیالوگ، برنده، کارت. بازی: لیوان، فاصله، مرموز، دستکش، ریسک، کیف |
| `زیرعنوان: ...` | زیرعنوان روی صحنه |
| `قانون: ...` | یک قانون (به ترتیب) |
| `زمان: 30` `جایزه: 10` | فقط برای مرحلهٔ بازی |
| `یادداشت: ...` | یادداشت کارگردان (دوربین، وسایل، افکت) |
| `گوینده (لحن): متن` | دیالوگ. لحن‌ها: هیجان‌زده، گرم و صمیمی، تعلیق، نجوا و رازآلود، جدی و قاطع، داور سخت‌گیر، شوخ و بامزه، کُری‌خوانی، آرام و توضیحی، حماسی، جشن و پیروزی، شوکه |

در مرحلهٔ «قوانین»، اولین دیالوگ مقدمه است و بعد برای هر قانون یک دیالوگ؛ هر قانون دقیقاً وقتی گوینده آن را می‌گوید روی صفحه ظاهر می‌شود.

## فایل قسمت (JSON)
خروجی «قسمت‌ها و ضبط‌ها ← خروجی» شامل کل قسمت + همهٔ صداهای نصب‌شده است. روی دستگاه دیگر «ورود قسمت» بزنید؛ صداها هم نصب می‌شوند. ساختار: `{format, project:{name, unit, startBank, players[], speakers[], theme, layout, segments[]}, voices:{items}}`.
