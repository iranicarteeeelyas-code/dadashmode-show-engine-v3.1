# تغییرات نسخهٔ ۳ نسبت به نسخه‌های قبل

## ادغام
- دو اپ `show-engine` (React/Vite، حدود ۳ هزار خط) و `ai-referee` (React + Express، حدود ۳۱ هزار خط، با پوشهٔ legacy تکراری) در یک اپ سبک و بدون مرحلهٔ build ادغام شدند. اپ جدید فقط با باز کردن در مرورگر اجرا می‌شود.
- از نسخهٔ قبل حفظ شد: بانک زمان (۲۰ ثانیه برای هر نفر)، الیاس قرمز ▲ کلید A و عماد سبز ● کلید L، شش راند با همان قوانین، استخر ۳ کارت خرابکاری، قدرت‌های ریسک زمان، رمزهای کیف و نسخهٔ کاغذی، VAR، دفتر وقایع غیرقابل‌حذف، هوش مصنوعی بدون اجازهٔ تغییر امتیاز، تصادفی محلی، و رنگ #FF00FF رزرو کروما.
- حذف شد: وابستگی به سرور Express و برنامهٔ piper و Gemini Live WebSocket، فایل‌های تکراری legacy، و ادعای «صدای زن آفلاین» که واقعی نبود.

## مشکلات گزارش‌شده و راه‌حل
| مشکل | راه‌حل در نسخهٔ ۳ |
|---|---|
| صدای زن کار نمی‌کند و دیالوگی گفته نمی‌شود | ریشه: فایل مدل و برنامهٔ piper در بسته نبود (docs/RESEARCH.md). راه‌حل: بانک صدای نصبی با Gemini/OpenAI، میکروفون یا فایل. پخش آنی و آفلاین، و ضبط مستقیم داخل ویدیو |
| گوینده باید دانلود و نصب شده باشد | صداها در ذخیرهٔ دائمی مرورگر و پوشهٔ `voices/` نصب می‌شوند و Service Worker همه را کش می‌کند. خروجی و ورود بستهٔ صدا هم دارد |
| احساس مناسب هر لحظه | ۱۲ لحن + دستور لحن آزاد برای هر خط. هوش مصنوعی هنگام درک سناریو برای هر خط لحن می‌گذارد |
| انیمیشن در سطح مسابقات تلویزیونی نیست | موتور رندر جدید: نوارهای ورود، تیتر با سایهٔ عمق، پرتوهای نور، کنفتی، نوارهای متحرک، انتقال مورب، کارت‌های بانک با شمارندهٔ غلتان، و افشای سینمایی جعبه، کارت خرابکاری، رمز و کیف |
| اتاق کنترل ناقص است | ترتیب اجرا با وضعیت و ثبت ایراد، ویرایش کامل هر مرحله، کنترل مخصوص هر راند، VAR، برگرداندن، تایمر، افکت‌ها، دیالوگ فوری، دفتر وقایع، دستیار کارگردان |
| درک کامل سناریو و دفتر کارگردانی | صفحهٔ سناریو با خلاصه، لحن، شخصیت‌ها، ضرب‌آهنگ و یادداشت‌های کارگردان، و ساخت خودکار مراحل |
| یک‌بارمصرف نباشد | چند قسمت، کپی برای ویدیوی بعدی، ورود و خروج قسمت، استفادهٔ دوباره از صداهای تکراری |
| بخش API key | Gemini و OpenAI با مدل‌های قابل تنظیم و تست اتصال |
| بخش جدا برای معرفی بازی و قوانین | استودیو معرفی: معرفی تمام‌صفحه با تصویرسازی مخصوص هر بازی، قوانین هم‌زمان با صدا، ضبط جدا + SRT |
| کیفیت یوتیوب و ذخیره در گوشی و فضای ابری | 1080p، 1440p یا 4K با 60 فریم، MP4/H.264، بیت‌ریت بالا، SRT، اشتراک به گوگل‌درایو روی گوشی و ذخیرهٔ خودکار در پوشهٔ همگام روی کامپیوتر |
| چیدمان استاندارد و قابل تغییر | جای کارت‌ها و تایمر، اندازهٔ زیرنویس، خطوط امن، کروما، تعداد بازیکن (۱ تا ۶) |
