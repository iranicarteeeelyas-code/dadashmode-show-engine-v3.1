# داداش‌مود · موتور نمایش ۳ (DADASHMODE SHOW ENGINE v3)

بازطراحی کامل و ادغام دو اپ قبلی (`dadashmode-show-engine` و `dadashmode-ai-referee`) در یک اپ. سیستم بانک زمان الیاس و عماد، شش راند، VAR، دفتر وقایع غیرقابل‌حذف و قوانین داور از نسخهٔ قبل حفظ شده‌اند. بقیهٔ اپ از اول ساخته شده است.

## اجرا در ۳۰ ثانیه
- **ویندوز:** روی `start-windows.bat` دوبار کلیک کنید. اپ در مرورگر باز می‌شود.
- **مک/لینوکس:** `./start-mac-linux.sh`
- **گوشی:** اپ را روی GitHub Pages بگذارید (بخش پایین)، آدرس را در کروم (اندروید) یا سافاری (آیفون) باز کنید و «افزودن به صفحهٔ اصلی» را بزنید.
- بدون سرور هم می‌شود `index.html` را مستقیم باز کرد، ولی در آن حالت نصب آفلاین کامل (Service Worker) فعال نمی‌شود.

> پیشنهاد مرورگر برای ضبط: Chrome یا Edge جدید روی کامپیوتر.

## قبل از روز فیلمبرداری (خیلی مهم)
1. **تنظیمات و API:** کلید Gemini را وارد کنید. همان کلید AI Studio که قبلاً داشتید کار می‌کند. بعد «تست اتصال» را بزنید.
2. **سناریو و کارگردانی:** فیلم‌نامه یا دفتر کارگردانی را بدهید و «درک کامل با هوش مصنوعی» را بزنید. یک قسمت کامل ۶ راندی آماده هم داخل اپ هست.
3. **صدا و گوینده:** صدای مجری را انتخاب و تست کنید (پیشنهاد: Leda یا Aoede). بعد **«ساخت و نصب همهٔ صداهای ناقص»** را بزنید تا شمارنده سبز شود (مثلاً ۵۵/۵۵).
4. در همان صفحه **«فعال‌سازی ذخیرهٔ دائمی»** را بزنید و یک **«خروجی بستهٔ صدا»** به‌عنوان پشتیبان بگیرید.
5. **اتاق کنترل ← تمرین و ضبط:** همهٔ تست‌ها را اجرا کنید: شروع، صدا، انیمیشن، امتیاز، پخش پشت‌سرهم همهٔ صداها، و اجرای کامل آزمایشی.
6. **تست قطع اینترنت:** اینترنت (یا Wi-Fi) را قطع کنید، اپ را دوباره باز کنید و یک بار کل نمایش را اجرا کنید. همه‌چیز باید کار کند.

### نصب صداها به‌صورت فایل کنار اپ (اختیاری)
اگر می‌خواهید صداها فیزیکی داخل پوشهٔ اپ باشند (مثلاً برای کپی روی چند دستگاه):
```
set GEMINI_API_KEY=کلید_شما          (ویندوز)
export GEMINI_API_KEY=کلید_شما       (مک/لینوکس)
node tools/build-voicepack.mjs episodes/ep1-time-bank.json
```
فایل‌های WAV در پوشهٔ `voices/` ساخته می‌شوند. اپ در اولین اجرا آن‌ها را خودکار نصب می‌کند. برای قسمت‌های خودتان، فایل خروجی قسمت را به این ابزار بدهید.

## کنترل راندها
- **برج لیوان:** برد (+جایزه)، تایمر اعتبارسنجی ۲ ثانیه روی صفحه، خطای دست دوم.
- **فاصله را انتخاب کن:** قفل خط سبز/زرد/قرمز، ثبت گل/خطا، ۳ تلاش (با کارت خرابکاری ۲ تلاش).
- **لقمهٔ مرموز:** توزیع مخفی محلی (دو +۱۵، یک دزدی ۵، سه پوچ)، انتخاب جعبه، افشای سینمایی.
- **دستکش و پازل:** برد +۱۵ و قرعهٔ کارت خرابکاری برای حریف با انیمیشن.
- **ریسک زمان:** خرید قدرت (قفل فوری)، دو برابر یا هیچ، بازگشت ALL IN (فقط یک بار و فقط برای نفر عقب‌تر).
- **توالی نهایی:** سه رمز محلی، نسخهٔ کاغذی برای چاپ، پیشرفت مرحله‌ای، ریست همان مرحله، باز شدن کیف طلایی.
- **VAR:** امتیازها قفل می‌شوند و روی صفحه اسکن VAR نمایش داده می‌شود.
- **برگرداندن:** هر تغییر امتیاز با یک رویداد جدید برمی‌گردد. دفتر وقایع هیچ‌وقت پاک نمی‌شود (خروجی CSV).

## میان‌برها
`Space` اجرا/مکث · `←` `→` مرحله · `A` و `L` برد راند برای الیاس و عماد · `1` تا `6` امتیاز دستی (`Shift` برای کم کردن) · `V` برای VAR · `Z` برای برگرداندن · `H` برای اعتبارسنجی ۲ ثانیه · `T` برای تایمر · `F` برای تمام‌صفحه

## انتشار روی GitHub Pages (برای نصب روی گوشی)
1. محتوای این پوشه را در ریپوی `dadashmode-show-engine-v1` (یا یک ریپوی جدید) روی شاخهٔ `main` بگذارید.
2. در GitHub بروید به Settings ← Pages ← Source و گزینهٔ **GitHub Actions** را انتخاب کنید. فایل `.github/workflows/pages.yml` آماده است.
3. آدرس `https://<نام‌کاربری>.github.io/<نام-ریپو>/` را روی گوشی باز کنید و آن را به صفحهٔ اصلی اضافه کنید.
4. در Google AI Studio کلید API را به همین دامنه محدود کنید.

## محدودیت‌ها (صادقانه)
- ساخت صدای زن با احساس به اینترنت و کلید API نیاز دارد، ولی فقط **یک بار قبل از فیلمبرداری**. پخش و ضبط کاملاً آفلاین است.
- موتور اضطراری روی دستگاه (Piper) صدای فارسی زن ندارد. صداهای فارسی آن مردانه‌اند.
- حین ضبط، تب مرورگر باید باز و جلو بماند (مرورگرها تب پنهان را کند می‌کنند).
- این نسخه در محیط ساخت فقط با تست منطقی و رندر بدون خطا بررسی شده است. قبل از فیلمبرداری واقعی حتماً اجرای کامل آزمایشی را روی دستگاه خودتان انجام دهید.
